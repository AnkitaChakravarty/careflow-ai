CareFlow AI – clinician trial kit

Run this on the observer’s laptop. Each task is done twice – today’s way (paper packet) and with CareFlow – and timed. Everything autosaves in this browser; export at the end.

Before you start (5 min)

  1. Reset the demo data so every trial starts the same: stop the app, rename data/careflow.db (e.g. to careflow.db.bak), start python app.py again.
  2. Make the paper packet: python docs/user_trial/make_paper_packet.py → open and print docs/user_trial/paper_packet.html (or show it on a second screen).
  3. Open CareFlow at http://127.0.0.1:8050 in the participant’s browser. He signs in as dr.mehta / mehta-demo-2026 (consultant – can do every step).
  4. Give a 3-minute tour only: Ward → a patient page → Ask CareFlow. Do not practise the tasks.
  5. Rules for the observer: start the clock when you finish reading the task aloud; stop when he says “done”. Don’t help unless he is stuck for 60 s (note it). The order of “today” and “CareFlow” alternates between tasks to reduce learning bias.

1 = strongly disagree, 5 = strongly agree
